# 3D Only Up Game

A simple 3D number merging game built with Three.js and Vite.

## How to Play

1. Click on cubes to select them
2. When two cubes with the same number are close, they merge into one
3. The merged cube has the sum of both numbers
4. Try to get the highest score before you run out of space!

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Build

```bash
npm run build
```
